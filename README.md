# 하루의 습관

모바일 브라우저에서 사용하는 개인용 습관 기록 앱입니다. 기록은 브라우저의 localStorage에 저장됩니다. 다른 기기와 동기화되지 않으며 브라우저 데이터를 삭제하면 기록도 삭제됩니다.

## 실행

`index.html`을 브라우저에서 열거나 정적 웹 서버로 제공합니다. 빌드와 패키지 설치가 필요하지 않습니다.

## GitHub와 Vercel 배포

이 폴더를 GitHub 저장소의 루트에 올린 뒤 Vercel에서 해당 저장소를 가져옵니다. 프레임워크는 Other를 선택하고 빌드 명령과 출력 디렉터리는 비워 둡니다.

## 기록 기준

- 예정된 습관을 하나 이상 모두 완료하면 완수일입니다.
- 습관이 없는 날은 연속 기록에서 건너뜁니다. 오늘이 미완료인 동안에는 어제까지의 연속 기록을 유지합니다.
- 습관 수정과 중단은 당일부터 적용되며 이전 날짜의 설정은 유지됩니다.
- 날짜는 기기의 현지 시간 기준입니다.
